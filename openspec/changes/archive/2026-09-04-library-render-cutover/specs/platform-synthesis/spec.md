## REMOVED Requirements

### Requirement: Synthesize a Platform value from typed inputs

**Reason**: `synth.Platform` wrote `version!` subscriptions that core `v2.0.0-alpha.7` removed (enhancement 0019, "A platform imports its catalog and embeds it whole into the registry entry, which derives everything else"); a platform is a CUE module importing its catalogs, generated by the frontend (enhancement 0019, "The Platform CR keeps naming a catalog coordinate; the operator generates the platform package").

**Migration**: write a platform module (`cue.mod` pinning the catalogs, `platform.cue` with `#catalog:` imports) and acquire it with `AcquirePlatformFromDir`.

### Requirement: Required inputs are validated with sentinel errors

**Reason**: the function and its sentinels are deleted.

**Migration**: none.

### Requirement: Subscription Synthesis

**Reason**: no subscription shape exists in core; entries embed the imported catalog and derive `version`.

**Migration**: pin the catalog in the platform module's `cue.mod`.

### Requirement: Kernel entry point returns a typed pre-materialize Platform

**Reason**: `Kernel.SynthesizePlatform` is deleted with the materialize step it fed.

**Migration**: `AcquirePlatformFromDir`.
