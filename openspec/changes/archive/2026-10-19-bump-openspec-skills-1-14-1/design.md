## Context

The skills were generated by OpenSpec 1.12.0. One file, `openspec-verify-change`, carries a local edit. 1.14.1 rewrites all eleven generated files.

## Decisions

- Regenerate with `openspec update --force`, then merge the local edit with `git merge-file`: the current file is "ours", pristine 1.12.0 output is the base, pristine 1.14.1 output is "theirs". A clean merge keeps the edit; a conflict stops the work.
- No pin and no gate: library runs no OpenSpec CLI gate. The later rewrite change adds a pinned 1.14.1 strict gate.

## Risks

- A skill file steers agents. The diff is checked for hidden Unicode and for text that widens permissions (`allowed-tools` lines stay as generated).
